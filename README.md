# Studio Collective

Public one-page site for [Studio Collective](https://studiocollective.dev).

**Turn up your creativity.**

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Pushes to `main` deploy via GitHub Pages (`.github/workflows/deploy.yml`).
Custom domain: `studiocollective.dev`.

Brand kit, social exports, and release runbooks live locally outside this public tree.
